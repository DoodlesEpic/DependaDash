DependaDash

Dependabot alerts across your repositories.

Independent project. Not affiliated with GitHub.

1

Choose a GitHub account

Use a personal account or organization. Your authenticated GitHub CLI user must be allowed to read its Dependabot alerts.

Enter a GitHub owner to generate the command.
2

Run the command

It scans visible repositories for that owner and writes open Dependabot alerts to a local TSV file.

Save the command as a .cmd file, then run it in Command Prompt.

# Enter a GitHub owner above.
Permissions: public repository access does not grant access to another account's Dependabot alerts. DependaDash only shows alerts your current gh authentication can read.
First time using GitHub CLI?
Install GitHub CLI, then run gh auth login and complete authentication. All shell versions use its built-in JSON filtering and do not require a separate jq installation. DependaDash never asks for or stores your GitHub token.
3

Load the generated file

The TSV is parsed locally in your browser.
